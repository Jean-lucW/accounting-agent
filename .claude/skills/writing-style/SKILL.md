# House style

The whole house style, for messages and for documents, is in `docs/COMMS.md`. Read it in full before drafting, revising or auditing anything, and follow its "Documents" section for any policy, procedure, briefing note, memo, process doc, rules file or summary.

After drafting, run `.venv/bin/python scripts/check_style.py <file>` and then read the draft for what the checker cannot see (the "Checking" paragraph in `docs/COMMS.md` lists it). Read the covering message against the same rules.
